# Transfer learning for predicting density and refractive index of ionic liquids
This repository contains transfer learning models and dataset described in the paper. The model can be trained using the google colab notebook code and data available in this repository.

# Abstract
In this work, we demonstrate the use of transfer learning in predicting the thermodynamic properties of ionic liquids at atmospheric pressure: model 1, from density at a fixed temperature to density at three different temperatures, and model 2, from density at various temperatures to refractive index at various temperatures. Two feature encoding methods are used, including method A, principal component analysis, and method B, SELFIES-collapsed features with non-zero permutation importance. We built dense neural networks with inputs stemming from IL physical structures to achieve automated prediction of properties. Predictive accuracies are assessed by Mean Absolute Percent Error (MAPE). If the average predictive accuracy using method A is <5% MAPE, method B will not be used. 
By transferring knowledge gained from predicting density at 298-299 K to predicting density at 283.15 K, 338.15 K, and 363.15 K, the average accuracies of target tasks with 50 data improved. Using method A, accuracy improved from 29.93%, 33.19%, and 32.84% MAPE (direct learning) to 11.48%, 13.23%, and 11.53% MAPE (transfer learning), and transfer learning works in 97%, 96%, and 99% of the cases, respectively. Using method B, accuracy improved from 6.25%, 8.18%, and 6.65% MAPE (direct learning) to 4.35%, 4.82%, and 4.56% MAPE (transfer learning), and transfer learning works in 70%, 86%, and 76% of the cases, respectively. 
Using knowledge gained from predicting density to predict refractive index, the average accuracy of target task with 50 data improved using method A, from 4.27% MAPE (direct learning) to 1.00% MAPE (transfer learning), and transfer learning works in 66% of the cases. Permutation feature importance analyses that show overlaps of key common descriptors offers an explanation for the transferability. This indicates that feature importance analysis may be leveraged for identifying whether transfer learning will work in predicting other thermodynamic properties.

# Dataset
For pure ILs, density and refractive index data at atmospheric pressure (101-102 pKa) are web-scraped from IL-Thermo version 2.0 34,35, an ILs database from the National Institute of Standards and Technology (NIST). Only pure ILs consist of two ions are collected. For the TL of density across temperatures, 604 density measurements at 298-299 K are collected for training to accomplish the source task; then, 182 density measurements at 283.15 K, 427 density measurements at 338.15 K, and 232 density measurements at 363.15 K are collected for the target task. For the TL from density to refractive index, 13371 density measurements (253.15-473.15 K) for the source task and 110 refractive index data (286.903-333 K) for the target task are collected. If there are multiple measurement results of a property for the same ionic liquid at the same condition reported on IL-Thermo, the average of these results is used. All datasets are available in this repository.
