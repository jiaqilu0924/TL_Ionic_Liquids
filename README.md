# Transfer learning for predicting density and refractive index of ionic liquids
This repository contains transfer learning models and dataset described in the paper. The model can be trained using the google colab notebook code and data available in this repository.

# Abstract
We demonstrate the use of transfer learning (TL) to predict thermodynamic properties of ionic liquids (ILs) at atmospheric pressure. We first use density at a fixed temperature as the source task and use TL to predict density at three different temperatures, our target tasks. We also use density at various temperatures as the source task to predict refractive index at various temperatures as the target task. We built dense neural networks (DNNs) with inputs stemming from the IL physical structures to achieve automated prediction of properties. Two feature encodings based on self-referencing embedded strings (SELFIES) of the ILs are used for the DNNs: principal component analysis (PCA) and SELFIES-collapsed features with non-zero permutation importance. TL of density at 298-299 K (source) to density at 283.15 K, 338.15 K, and 363.15 K (targets) using the PCA features shows the mean average percentage error (MAPE) improved from 29.93%, 33.19%, and 32.84% to 11.48%, 13.23%, and 11.53%. TL using the SELFIES-collapsed features also showed improvement from 6.25%, 8.18%, and 6.65% MAPE to 4.35%, 4.82%, and 4.56% MAPE. Similarly TL using density as the source task and refractive index as the target task with PCA features, showed improvement from 4.27% MAPE to 1.00% MAPE. Permutation feature importance analyses show overlaps of key common descriptors, explaining the TL success. This indicates that feature importance analysis may be leveraged for identifying whether TL will work in predicting other physical properties.

# Dataset
For pure ILs, density and refractive index data at atmospheric pressure (101-102 pKa) are web-scraped from IL-Thermo version 2.0, an ILs database from the National Institute of Standards and Technology (NIST). Only pure ILs consist of two ions are collected. For the TL of density across temperatures, 604 density measurements at 298-299 K are collected for training to accomplish the source task; then, 182 density measurements at 283.15 K, 427 density measurements at 338.15 K, and 232 density measurements at 363.15 K are collected for the target task. For the TL from density to refractive index, 13371 density measurements (253.15-473.15 K) for the source task and 110 refractive index data (286.903-333 K) for the target task are collected. If there are multiple measurement results of a property for the same ionic liquid at the same condition reported on IL-Thermo, the average of these results is used. All datasets are available in this repository.
